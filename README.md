# AchievementBrowser — Community Marker Pack

Community-contributed POI markers for the **GW2CC AchievementBrowser** plugin.
Distributed as `AB_Community.taco` + `manifest.json`. Source of truth lives in
the private `gw2cc-ab-internal` repo; this repo is published automatically.

Each release below lists the achievements and markers added/changed.
